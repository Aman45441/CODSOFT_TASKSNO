# CODSOFT_TASKSNO

This repository contains three CodSoft projects. Each project is in its own folder with a standalone HTML file and a project README.

## Project 1: Tic-Tac-Toe AI

A Tic-Tac-Toe game against an AI using Minimax search with alpha-beta pruning.

- [Open Project 1](./Project1/)
- [Project 1 README](./Project1/README.md)

## Project 2: Rule-Based Chatbot

Milo is a browser chatbot that responds to common phrases using JavaScript rules.

- [Open Project 2](./Project2/)
- [Project 2 README](./Project2/README.md)

## Project 3: Movie Recommendation System

Frame recommends movies based on selected genres, moods, and runtime.

- [Open Project 3](./Project3/)
- [Project 3 README](./Project3/README.md)

## Run a project

Open the project folder and launch its index.html file in a modern web browser.
